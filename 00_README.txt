BehaviorLab 用户行为序列仿真器 · Windows 免安装版

第一次使用，只做这 3 步
1. 把 ZIP 复制到另一台 Windows 10/11 的 Intel/AMD 电脑。
2. 右键 ZIP → 全部解压，例如放到 D:\BehaviorLab。一定要完整解压，不要在压缩包里直接运行。
3. 打开解压后的文件夹，双击 01_START.cmd。默认浏览器会自动打开系统。

不需要安装 Codex、Node.js、Python、Docker、数据库，也不需要管理员权限。
包内已带 Node.js 24.19.0 Windows x64 运行时。当前 Mock 演示无需联网或模型密钥。
请放在你有写入权限的普通本地目录，不要放到 Program Files 或只读共享盘。

每天如何用
• 打开：双击 01_START.cmd。重复双击会打开同一个后台服务。
• 停止：双击 02_STOP.cmd。用户、任务和截图会保留。
• 关浏览器不会关闭后台服务；正常启动成功后，启动窗口会自行关闭。
• 重启电脑后，再双击 01_START.cmd；没有配置开机自启。
• 默认地址为 http://127.0.0.1:4317/。如端口被占用，会自动换到空闲端口并打开正确地址。
• .runtime\desktop.json 中的 url 是本次运行地址；不要分享其中的 token。

怎么看完整演示
1. 用户库：查看已有用户，或点创建用户，审核候选后入库；也支持手动创建。
2. 仿真任务：新建任务，选用户、日期跨度、APP，再进入任务详情。
3. 运行总览：先生成计划，推进下一活动/一个用户日，或连续生成；可暂停和恢复。
4. 同一任务内查看行为规划、执行记录、生成记忆和调用调试。
5. 如需 JSONL 或检查报告，在任务内重新执行导出/检查。

这个包包含什么
带数据包：包含打包时的用户库、任务进度、计划、实际结果、截图、观察文字和调用记录。
干净包：不含原电脑数据，第一次启动后从创建用户开始。
具体数据数量、快照时间及运行时来源见 portable-manifest.json。
迁移不带旧导出文件，以免它们继续指向原电脑路径；在新电脑按需重新导出。
历史调用中记录的原电脑路径是原始证据，保留原样，不影响新电脑后续运行。

当前能力边界
用户管理、事件调度、虚拟时间、持久化、调用关联是真实运行的架构逻辑。
人设补全文本、大模型规划、手机操作、截图、图转文字仍为明确标识的 Mock。
包内示例与历史数据是合成演示数据，不是真实手机采集或真实用户行为数据。
本包仅供在部署电脑本机使用，不提供局域网/公网访问、多人账户或线上生产部署。

以后备份 / 再换电脑
1. 先在页面暂停任务，等待当前活动完成，再双击 02_STOP.cmd。
2. 把整个 BehaviorLab 文件夹复制或压缩，拷到另一台相同类型的 Windows 电脑。
3. 在新电脑双击 01_START.cmd。旧电脑的 .runtime 不需要复制，误复制也会重新识别服务。
进度都在 .data 文件夹中。不要只复制网页文件，也不要在任务运行时单独复制一个 .sqlite 文件。
更新程序时保留 .data；不要拿另一份旧数据覆盖已经继续运行的新电脑数据。

遇到问题怎么办
• 没有自动打开浏览器：查看启动窗口提示的 READY 地址，手动复制到 Edge/Chrome 打开。
• 网页打不开：重新双击 01_START.cmd；自动换端口后不要继续用旧收藏地址。
• 闪退或提示找不到运行时：重新完整解压，确认 runtime\node.exe 存在。
• 启动报错：查看 .runtime\server.log；反馈时附上报错文字及 Windows 版本。
• 权限不足：把整个文件夹移到自己有写入权限的位置后再启动。
• 公司电脑策略禁止运行 CMD/EXE：交给管理员按公司流程放行，不要关闭安全软件。

打包与验证记录见 docs\WINDOWS_PORTABLE.md。
