# v0.4 部署、升级与回退

适用正式版：`v0.4.0`，Windows 10/11 x64；2026-10-31用户已恢复正式发布授权，保留旧预览版本和附件。项目组内部使用按下列步骤部署。

## 安装与校验

从[v0.4.0 Release](https://github.com/rexyangqaq-a11y/BehaviorLab/releases/tag/v0.4.0)取得 `BehaviorLab-v0.4.0-Windows-x64.zip` 和 `SHA256SUMS.txt`。GitHub 自动生成的 Source code ZIP 不含运行依赖。

```powershell
Get-FileHash .\BehaviorLab-v0.4.0-Windows-x64.zip -Algorithm SHA256
```

与校验表同名行完整比较，解压到可写新目录，不在压缩包内运行。包内含 Node 24、Python 3.12、三框架、HDC、Java／视频组件和已审阅历史；USB 驱动、设备授权及自己的模型服务仍由操作者准备。

1. 运行 `03_CHECK.cmd`，检查依赖、哈希和固定离线循环，不请求供应商或手机。
2. 运行 `01_START.cmd`，按启动器给出的地址打开网页，默认 `http://127.0.0.1:4317`。
3. 端口被占用可能自动选空闲端口，以 `READY` 和该目录 `.runtime/desktop.json` 为准。
4. 停止使用 `02_STOP.cmd`；关闭网页不停止后台服务。保留本地数据。

实际操作见[使用指南](USER_GUIDE.md)。只查看历史或运行 Mock 不需要手机／模型；不要为验证安装自动开始真实任务。正式包离线、doctor、启动／停止及下载验证见发布记录；它们不等于目标电脑、设备和长任务已经验收。

## 升级和本地数据

先停止本机任务、投屏、HiLog 及旧服务，备份完整已用目录，包含 `.data`、必要 `.runtime` 配置和 SQLite WAL。不要运行中只复制某个 `.sqlite` 文件。

将新包解压至新目录，核对数据版本和兼容说明，再复制需要保留的本人 `.data`。不要把更高 schema 的主仿真库回退覆盖进 v0.4；不要把私人 `.runtime` 整体覆盖到新依赖目录。同一 Windows 账户的新保存密钥受 DPAPI 保护；跨账户迁移应按[密钥迁移说明](PRIVATE_MIGRATION.md)操作，不能把无法解密当作空密钥覆盖。

已有同 ID 的用户任务、停用状态和起点选择不被随包任务初始化覆盖。旧目录完整保留作回退；不要删除 `.data`、删除未知锁或使用 Git reset 来代替升级。运行中端口属于哪个目录，应先核对再停止。

## 回退与边界

正常停止新服务后，用旧目录及其匹配备份启动。回退不等于用旧代码打开新数据。新的任务运行、原始日志和截图未自动加入公开或内部交付包，按具体范围审阅后分享。

Windows 包是本机桌面工作台，不是已部署的多人服务器；第二台物理电脑、驱动、资源管理器双击及真实业务需分别核对。第三方依赖声明随包保留，见[组件清单](THIRD_PARTY_COMPONENTS.md)。

源码开发、独立端口和离线验证见[开发指南](DEVELOPMENT.md)；已知代码风险见[审查报告](CODE_REVIEW_V04_20261030.md)。
