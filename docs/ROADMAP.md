# 版本计划

更新：2026-10-25。这里区分发布、开发和计划；未承诺日历日期。功能计划依据 [VERSION_PLAN](VERSION_PLAN.md)，未来版本仍按逐轮讨论、需求核对、概要设计核对、实现与验证推进。

| 版本 | 状态 | 主要交付与边界 |
|---|---|---|
| v0.3 | 历史工程基线 | Mock 用户库、任务、调度、持久化、执行／描述分离及导出；不代表真实手机闭环 |
| v0.4.0-preview.10 | 本次首发候选 | 独立真机工作台、三框架与模型配置、默认推荐、轨迹与结果查看、离线保护。附当时的测试用例和36项历史矩阵档案；仍是预览版 |
| v0.5 | 开发分支 | 下层接入主调度、通用活动、实际量与证据、有界恢复和人工兜底；目前首轮离线实现，原生主会话及真实验收未完成 |
| v0.6 | 计划 | 真实人设生成、每日规划与活动后局部调整；保留用户隔离、模型原稿和调用记录 |
| v0.7 | 计划 | 存档截图逐图 VLM、原文与来源、失败补跑、首个约定范围的完整真实样本 |
| v0.8 | 计划 | 跨日、多用户、复杂活动与中断恢复；报告行为和图文质量 |
| v0.9 | 计划 | 长周期数据查询、预算、积压、备份及迁移，披露实测容量与成本 |
| v1.0 | 计划 | 在约定设备、APP、模型及预算下可重复部署、运行、恢复和消费数据；包含目标电脑验收 |

每版必须附独立测试用例、可操作的测试调试入口、证据、已知问题和更新／回退说明。工程测试、历史真机结果、当前版本真机复测和第二台电脑验收分别报告。

发布使用 `v主版本.次版本.修订版本` 标签；尚未达到完整门槛时使用 `-preview.N` 并在 GitHub 标为 Pre-release。历史 v0.3 未补造 Release，未来版本不提前发空包。v0.5 的开发进度以开发分支文档为准，不反写进 v0.4 历史测试记录。
