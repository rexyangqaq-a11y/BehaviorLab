### 当前源码中必须处理的接入阻点

- `normalizeConfig` 仅接受 `mode=mock`；`assertAdapters` 要求所有内容适配器来源模式等于整个 Run 模式。因此“真实规划 + Mock 手机”目前也不能直接装配。
- Web 初始化、人设预览、worker、CLI 都直接创建 `createMockAdapters`。只换模型 URL 不能完成接入。
- `/api/system` 以及多处界面文案写死 Mock；事件级 `synthetic` 目前由 Run 的模式推导。真实接入前需区分模块输出、截图来源与虚拟用户属性，具体新字段不能只在一个页面临时添加。
- `titleStatus` 未纳入作业失败状态，就可能根据 `dataset_complete` 显示完成；应保留各阶段事实，而不是交换一个标签后仍丢失失败原因。
- 同一 Run 的 execution 租约不等于跨 Run 的真机锁；当前完整快照与前端分页不等于支持长周期的服务端分页。

## 5. 推荐的开发顺序与阶段出口

```mermaid
flowchart LR
 A[当前 Mock 基线] --> B[v0.4 最高优先<br/>开源下层选型与最小验证]
 B --> C[v0.5 按选型接入系统<br/>必要装配、来源与设备控制]
 C --> D[v0.6 真实用户与上层规划]
 D --> E[v0.7 存档 VLM<br/>首个完整真实闭环]
 E --> F[v0.8 跨日、多用户与恢复]
 F --> G[v0.9 长周期治理<br/>v1.0 明确范围交付]
```

**下一轮范围：FW-01 + VT-01 的 v0.4 部分。** 先比较、验证和收敛框架，随 v0.4 落实该版独立用例与测试调试界面，不提前设计后续版本。ST-02 与 AD-01～03 按最小试验/实际接入需要分步完成，主要集成落在 v0.5；不先建设完整通用配置平台，也不重新搭建已有调度与用户库。旧 Mock 闭环、恢复、排序与隔离继续作为回归基线。

**下层验证先用手工/Mock 上层活动。** 真实人设/上层规划排入 v0.6，不再作为手机 Agent 验证的前置条件。下层需要的实时视觉与存档 VLM 分开：前者在 v0.4～v0.5 验证，后者 v0.7 合入完整样本。上层只决定做什么和活动后调整，调度器只管理进度。

**真机与 VLM 是两条可分别验证的工作线。** 先验证工具、单对象浏览、停止/恢复，再接多对象比较；实时页面视觉服务下层决策，存档图转文服务研究数据。可共用模型服务，但用途、提示和输出分开；不能要求每步操作等待存档队列。

**第一轮真实采集验收出口**：指定的一个 APP 中，固定用户有真实上层规划、真实设备动作/图像、实际结果与上层反馈、逐图 VLM 原文及完整来源；先一项活动，再一天。样本量、允许动作和成本上限在试验前确认。未接入部分仍可独立验证，但不能称整条真实闭环。

**扩大前评审**：用短周期证据讨论用户差异、跨日稳定/重复、偶然行为、摘要是否足够、对象量核对、账号串扰、VLM 错字/幻觉及吞吐。必要时再引入短技能、调整上下文或增加隔离；不先建设完整年度系统。

## 7. 保留的约束和暂不扩展项

- 已确认：简单固定人设，用户隔离；程序管进度，上层管每日行为与调整，下层管页面执行；计划/实际、虚拟/真实时间、原文/加工分开；执行和逐图描述分别推进。
- 暂定：单活动单 APP、首版可能共用账号；账号推荐状态串扰仍需披露和验证，不能当作已解决。
- 工程默认：Node/SQLite、近期窗口 5、描述最多 3 次、批次 1–20、截图一图一事件、上面的迭代优先级和重试等待。均不升级为用户硬要求。
- 待讨论：是否需要行为库/短技能、下层框架、VLM 在手机端/采集主机/云端的选择、文字加工规则和行为质量阈值。当前推荐先不做全年行为脚本库，不指定新模型采购或端侧硬件。
- 本阶段不建设：记忆提取/融合/检索引擎、动态偏好演化、APP 历史世界、多机分布式、全 APP 通用 Agent、自动交易或完整年度生产系统。

## 8. 后续进度怎样更新

每项只在实现和相应验证完成后改为完成，并记录修改文件、运行方法、证据与限制；设计、模拟服务测试、真实服务验证、GUI 验证和另一台电脑实测分别记录。发布构建另列，不能因为源码修复就声称旧 ZIP 已更新。

每版独立用例与测试调试界面是完成条件；具体内容随版落实，缺少或未验收时不得记为该版完成。

当前记录：ST-01 源码完成，AD-02 配置管理完成，FW-01/VT-01 的 v0.4-preview.1 部分已交付；后续继续框架真实循环验证。独立 8 项与全量 44 项通过，已有可操作的本版预览调试界面；正式 v0.4 仍缺真实模型/设备链路与候选决策。对动作粒度、下层完成核对、组合来源语义等架构决定，按证据逐项讨论，不一次定下整个长期系统。
