## 如何使用

通过现有 `01_START.cmd` 启动系统，打开「系统设置 → 模型服务」。默认地址为 [模型服务设置](http://127.0.0.1:4317/#/settings)；启动器如另选端口，以启动结果为准。旧服务更新源码后需要重启。

1. 点击「添加服务」，填写便于辨认的名称。可以先保存草稿，之后再补账号信息。
2. 准备好服务后，填写平台、接口协议、完整模型 ID、服务根地址、鉴权方式和超时。平台名称与协议是配置字段，目前没有实际请求适配器；选择它们不表示已经兼容该服务。
3. 在「角色预设」中分别为用户生成、每日规划与调整、手机观察与决策、截图转文字选择服务。同一服务可供多个角色使用，也可以暂不指定。
4. 点击「保存配置」。刷新页面或重启服务后可继续编辑；「还原修改」只撤回当前未保存的编辑。
5. 「检查已保存配置」核对地址、模型名和所需密钥是否齐全。它不会发送请求；字段齐全也仍显示连接未验证。

当前生成、规划、手机执行、截图与描述仍使用原有 Mock。角色预设不会切换运行适配器，不会改变已创建任务。

## 本机保存与迁移

配置和凭据保存在数据目录的 `.model-services.sqlite`，与任务和研究导出分开。密钥由本机后端保存，读取配置时只返回是否已有密钥，不回填原值；前端不写入浏览器本地存储。编辑时 API Key 留空保留原值，输入新值替换，点击「移除已保存密钥」后保存则删除。删除服务或改为无需鉴权也会移除对应密钥。

本版 SQLite 中的密钥未加密，访问该本机文件的人可以读取。配置不写入任务 Trace 和研究导出；现有便携包构建使用明确的复制清单，不复制该配置库及凭据。换电脑时通过页面重新填写。2026-10-19 的历史 ZIP 不含本次页面，本轮没有重打包。

多页面修改采用配置版本校验：旧页面保存时会收到冲突提示，不能覆盖已保存的新版本。
