# 本地网页调试台

> 历史版本说明：此调试台已由 v0.2 系统业务页面替代。当前入口与运行方法见 [WORKSPACE_V02.md](WORKSPACE_V02.md)，下文记录原 Demo 的实现与验证。

启动：双击 `start-web.cmd`，或在项目目录运行 `node src/web-server.mjs`，再打开 `http://127.0.0.1:4317`。启动器优先使用 PATH 中的 Node；未找到时尝试本机 Codex 已有的 Node 运行时。仍需 Node.js 24，不自动安装软件。

调试台以原生 HTML/CSS/ESM 实现，原生 Node HTTP 提供本地 API。没有前端模拟的假进度；界面轮询现有 SQLite 与任务记录，不改动上下层职责。已有 CLI 运行自动列出，目录内不是有效运行的条目会显示错误且不可选择。

## 推荐试用路线

1. 点击「新建运行」：修改运行 ID、虚拟日期、用户数量、每步演示间隔，以及两个故障开关。可展开 JSON 修改原始人设和其他配置；JSON 是最终提交内容，快捷表单输入会同步到 JSON。创建后配置只读，修改需另建运行，避免重解释已采集数据。
2. 点击「创建并跑完整流程」或已有运行的「一键跑完整流程」。依次执行原有采集/反馈流水线、显式失败描述补跑、导出和离线检查。检查存在缺项时任务显示“完成 · 有缺项”，不能冒充检查通过。
3. 看四组状态：执行结果、活动后反馈、逐图描述、证据完整性。`partial` 是部分完成的已结束事实；描述和检查有各自进度。虚拟活动日与实际采集时刻独立展示。
4. 通过用户/日期筛选「活动序列」；点击记录对比计划对象数与实际完成数，查看上层决定。使用「计划版本」查看原计划与局部替换；「图像与描述」可筛未完成项，查看动作前/后图像、原始描述、错误、尝试历史和加工来源；「审计日志」按真实记录时间显示最近 300 条。
5. 完成后下载 `events.jsonl`、`run.json`、`check-report.json`。下载是最近生成的快照；数据变化后需重新导出。图像资产仍在对应运行目录的 `assets/`，不包含在这三个文件内。

## 故障与分步调试

| 操作 | 用途 |
|---|---|
| 执行 / 恢复 | 读取既有状态，继续执行并后台描述；成功的活动不重采；失败描述保留直到显式补跑 |
| 仅推进执行 | 不开启描述 worker，用来观察两阶段独立进度 |
| 补齐待描述 | 只处理 pending 和可恢复的中断项，不自动重试 failed |
| 描述补跑 / 重试失败描述 | 显式补失败与后继缺项，遵守原有尝试上限 |
| 动作记录后中断演练 | Mock 子进程在动作意图和两张图像已保存后直接退出（退出码 73），展示 executing 日志、尚无活动结果和未完成描述；再执行/恢复，执行器必须授权续跑 |
| 停止任务 | 仅停止当前服务启动的任务子进程，网页服务继续运行；保留已保存事实，之后可恢复 |
| 导出 / 检查 | 直接调用原导出与离线检查模块；检查不自动重规划 |

中断演练要在尚有待执行任务的运行中使用；已结束的运行不会重新执行来制造故障。默认示例对每个用户首项活动的一张图注入首次描述失败，按序阻塞该活动后继图像，其他活动可继续描述。关闭故障注入则不会出现该测试情景。

## 任务管理与边界

每个网页任务使用独立子进程；同一 Run 在网页中只允许一个活动任务。CLI worker 正在使用该运行时，网页拒绝另行启动。`web-job.json` 保存最近任务的阶段、错误、真实起止与 PID；系统进度仍来自 SQLite，刷新页面不丢进度。

停止网页服务时会停止它拥有的子进程。服务异常退出、但任务子进程仍存活时，重新打开的服务会保守显示任务仍在运行，不接管/终止仅凭历史 PID 发现的进程；子进程结束后恢复正常。如需人工处理，应先检查对应进程。死进程留下的 lease 不会禁用网页恢复按钮；接管仍遵守原执行器恢复协议。

HTTP 只绑定 loopback，写入限定本地来源和 JSON API。用户输入不能指定任意文件路径或 shell 命令；运行目录与下载文件受限。此服务用于本机少量用户、短周期 Demo，尚无远程鉴权、年度数据分页和多设备调度；不应作为公网服务部署。现有 Mock 与真实接入条件保持不变。

## 验证结果

原 13 项工程验证加 5 项网页 HTTP 集成验证，共 **18/18 通过**。新增覆盖完整流水线与文件下载、真实子进程中断恢复、手动停止与并发拒绝、分步失败描述补跑、来源与目录/命令边界。

另在真实浏览器界面验证：创建并执行 Demo、快捷配置同步、动作记录后中断并恢复、按用户筛选失败描述、逐图证据详情。Windows 沙箱内启动的服务无法从桌面浏览器访问；授权在正常本机环境启动后预览可用。以上证明 Mock 工程流程可调试，不证明真实手机 Agent 或行为自然性已实现。
