# v0.4 手机框架接入 Spec

标识 ADAPTER-V04 / R1；2026-10-30；描述当前真实适配边界，引用 PRD Q03/Q05–Q09。三框架已保留并由用户选择，本页不是重新进行唯一框架选型。

## 固定入口

`src/phone-framework-registry.mjs` 是固定允许列表，定义 ID、版本、adapter、必要源码文件。worker 按注册项加载 `integrations/adapters/<adapter>.mjs`，调用异步 `run(context)`。网页不得传入任意模块路径。Midscene 原生 SDK 与 Python 原生循环两类入口复用同一执行边界。

## 当前 context 与返回

| 字段／操作 | 生产方与语义 | 副作用／限制 |
|---|---|---|
| `input`、`prompt` | worker 的冻结任务、起点、服务元数据、限额与实际提示 | 不重新读取可编辑任务代替冻结输入 |
| `session` | 设备会话：观察、布局、尺寸、效果状态、动作事务 | 物理输入必须先记录意图，单位以协议和已观察屏幕为准 |
| `transport.fetch` | 审计与定位恢复后的模型运输 | 原始请求／回复／usage均保留；不能另建 SDK 客户端绕过 |
| `evidence` | 单运行追加日志、图像、哈希与持久化 | 不写业务通过；不允许并行无协调写同一账本 |
| `dispatch(name,param)` | Python RPC 到公共动作门禁 | 权限、坐标、计数、重复保护与原子观察，未知效果不重放 |
| `counter`、`repeatGuard` | 框架动作计数与保护 | 物理输入由设备另计；不按请求／截图数猜动作数 |
| `control.signal` | 停止与期限 | 取消要停止新输入并保留在途不确定性 |
| `deferCleanup(fn)` | 延迟关闭共享 SDK 设备会话 | worker 最终观察和结果落盘后执行，不能提前断连 |
| `service`、`key` | 父 worker 内使用的服务与密钥 | Python 子进程不接收密钥；日志与导出必须清洗 |

adapter 返回原生结果或抛错；结束不直接授予业务通过，最终仍需独立核对。拥有的子进程在 `finally` 关闭，监听器取消；共享 SDK 通过延迟清理收尾。输入锁异常退出的已知缺口见审查 R01，不能宣称已具备任意崩溃安全续接。

## 接入顺序与验收

1. 注册固定版本、来源、adapter 入口和实际执行源文件，不能只改下拉框。
2. 在 adapter 实现 `run(context)`；复用计量、设备与证据边界，不发送密钥到 Python／stdout。
3. 明确支持动作、坐标空间、缩放、方向、截图 MIME 与文本编码。不支持时显式失败，不兜底为 finish。
4. Python 桥使用显式 runner 注册，不将未知框架默认路由到已有 runner。保留原生解析与框架行为。
5. 维护依赖部署、doctor、源清单及打包资源；局部路径通过运行时解析，不硬编码个人目录。
6. 定向工程测试 → 已安装原生循环固定回复 → 显式授权的真实小任务，分别报告。纯文档与接入准备不启动第三步。

新测试默认不限请求／步骤／动作／时间／模型等待，按冻结限额判断；网络自动重试仍关闭。可识别的执行前坐标纠正最多新增两次请求，是受审计的新请求，不是重放设备动作，也不绕过额度。发生未知效果、未知 usage、权限、方向变化或停止时不能借纠正继续。

验收包括非法动作未送出、中文与 MIME 往返、取消、耗尽、未知效果、SDK 收尾与原始证据完整。修改动作、提示、坐标、解析或采集语义时升级协议并冻结必要来源；只增加解释性注释不改变既有业务协议。新增运行不改历史 input/result/asset。
