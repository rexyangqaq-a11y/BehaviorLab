## 后续接入的工程默认

以下是为控制用量采用的工程默认，不是用户指定的具体预算数值：

- 保存配置、打开页面和环境检测不触发模型请求。
- 连通测试仅在需要时执行一次短文本请求，明确限制输出长度；不默认把三个模型全部跑一遍。
- 不自动重试，不静默换模型，不默认启动批量测试或持续 Agent 循环。
- 调用前设置步数、请求次数、上下文与输出上限；调用后记录服务返回的输入/输出及可得的缓存、思考 token。未返回的用量记未知，不记为零。
- 真实手机决策与存档图转文分开计量。先用最小测试输入核对图像与动作能力，不以模型名称推定兼容。

主系统尚未接入真实请求适配器；以上是后续实现约束，不宣称已经具备完整的预算控制、计费或用量统计平台。短文本连通已通过，图像/动作/框架能力仍待验证，框架最终选择仍由用户决定。Token Plan 对应用后端/非交互式自动化调用的使用范围限制已在预算报告核对，后续批量仿真需使用允许该用途的服务。
