# v0.4 汇报PPT精简重构

2026-10-23。按用户最新要求参考“文档生成”对话中第五版三页方案图的信息组织、框图层次、反馈路径和同维度比较表，将2026-10-22的20页汇报重组为8页。保留四部分内容与原16:9物理尺寸，另存新副本，不覆盖旧PPT或参考材料。

## 整体逻辑与单页职责

| 页 | 要回答的问题 | 主要表达方式 |
|---|---|---|
| 1 | 下层操作在系统中负责什么、如何形成闭环？ | 三层边界、六模块闭环、反馈路径、公共保护与证据侧栏 |
| 2 | 一次真实任务怎样调用模型、设备并留证？ | 五泳道时序图、源码职责、请求/框架动作/物理输入计量表 |
| 3 | 为什么选择这三个框架参加测试？ | 入选条件流程、同维度比较表、其他调研对象的用途 |
| 4 | 测什么、怎样算通过、怎样保证起点可比？ | 四条任务操作流程、分别验收与禁止项、四阶段矩阵补齐 |
| 5 | 36个单元的真实结果及组合差异是什么？ | 完整36格状态矩阵、框架/模型汇总、候选判断与边界 |
| 6 | 哪些性能样本可比、消耗差在哪里？ | 同模型成功样本表、可编辑用量条形、输入占比与累计账本 |
| 7 | 哪些失败来自接入，哪些仍需区分原因？ | 五环节动作链、确认修复案例、具体坐标链、其他失败诊断表 |
| 8 | 下一阶段按什么依赖顺序推进、如何验收？ | P0/P1/P2路线、验证依据表、当前实现与未完成边界 |

数据仍为四题三框架三模型的36项探索性实测，16通过、10部分完成、10未通过。保留协议差异、单次样本、用户待复核、最终框架未定等限制。既有39条真机运行、应用代码和其他对话中的开发工作不属于本轮修改范围；本轮不操作手机、不调用模型、不重建部署包。

## 可编辑性与验证

- 使用原生文本、形状、9个表格和47条单对象原生路径；多段箭头以路径自身端点表示，虚线采用原生线型。
- 文本在同一段落框内换行，不将自然段拆成视觉行。普通对象移除禁止组合锁，原生表格保留其PowerPoint固有组合限制。
- 导出后逐格核对36格判定及6个同模型通过样本的耗时、请求和tokens；逐页静态预览、字体度量、尺寸/结构及首方导入检查。
- 静态预览使用实际OOXML几何与本机字体度量；未做PowerPoint实机验证，不宣称已覆盖其实际字体回退和编辑弹窗行为。
