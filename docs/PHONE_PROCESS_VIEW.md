# 测试过程详情

2026-10-23，0.4.0-preview.8。本机入口：<http://127.0.0.1:4317/phone-lab#process>。

## 当前用例与轨迹

启动单项测试或组合评估后自动进入“测试过程详情”，跟随当前正在执行的用例。页内显示执行时冻结的名称、任务版本、框架/模型、手机型号、起点、任务要求、禁止操作与限额。模型请求、框架动作、执行段耗时、已知 tokens 分别统计，不把请求数等同于动作数。

轨迹每秒读取已有 JSONL 记录，按游标增量传输；不会为展示额外请求模型或截取手机屏幕。模型步骤包含原始判断字段、完整回复、实际提交的图像引用和关联动作；动作步骤包含参数、返回/未知状态、动作期间的 HDC 日志和前后图。读取到尚未写完的一行时，下一次刷新继续读取，不补写回复。

默认跟随最新步骤；点击旧步骤会暂停跟随，避免阅读时跳走，“跟随最新”可恢复。结果页与过程页的选择状态独立。结束后本页保留刚查看的用例，明确显示等待业务核对；点击“前往结果与判定”复核，框架结束或动作返回均不自动判通过。新打开且空闲的过程页不会将旧历史标成正在测试。

## 连续视频已接入

按用户指定接入[HOScrcpy](https://gitcode.com/OpenHarmonyToolkitsPlaza/HOScrcpy)后台SDK：点击“开始投屏”后直接观看手机H.264视频，支持停止与全屏，离开过程页自动释放。无需打开官方工具或选择桌面窗口。视频与左侧执行证据图分开，视频流不增加模型请求或任务截图，不作为单次业务通过依据。

建议先投屏再开始任务：SDK启动会连接/初始化自己的设备端服务，与任务准备互斥；已接通后可继续测试。新任务冻结启动时投屏状态及参数，避免与未开启投屏的性能样本混比。视频仅观看、不录音、不自动录像、不上传；状态检查不启动采集。断流明确提示，检查USB及解锁后手动重连，不自动重放动作。

当前手机SGT-AL10/API26已验证真实视频解码、桌面滑动同步、HDC布局共存、主动停止及重连/离页回收。首段断流保留实况，未将其计为稳定通过；长时与三框架完整业务共存尚待后续采样。本机依赖、安装教程、固定版本和验收边界见[详细说明](HOSCRCPY_VIDEO.md)。窗口共享旧实现已在preview.7回退，当前页面使用新的直连通道。
