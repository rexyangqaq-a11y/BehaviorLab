# 私人任务、历史和模型配置迁移

2026-10-23，preview.9。私人迁移版含本机真机工作台的6个任务、83个起点、39条运行、批次/评估/判定、原始截图与逐步回复，以及3个模型服务和角色配置。它包含私人历史截图，请在本人授权电脑间保存和传递。

## 原电脑

部署ZIP之外另有`BehaviorLab-Migration-Key-20261023`目录。在原电脑、同一Windows账户下运行其中的“查看迁移密码.cmd”，记下显示的随机密码。密码只用Windows CurrentUser DPAPI密文保存，没有写入聊天、日志或ZIP。此查看目录搬到新电脑后无法解密，需先在原电脑查看。

## 新电脑

1. 完整解压`BehaviorLab-Phone-Windows-x64-20261023-Private.zip`到新的可写目录。
2. 运行`03_CHECK.cmd`完成离线依赖检查。
3. 运行`04_IMPORT_KEYS.cmd`，输入迁移密码。输入不显示，密码不放进命令行参数、不保存到文件。API密钥通过认证后按新电脑的Windows当前账户用DPAPI加密写入数据库，不发起模型请求。
4. 运行`01_START.cmd`。真机工作台可看到全部任务、起点和历史；模型服务名称、地址、模型、绑定及密钥已恢复。系统仍不自动调用模型，不会续跑历史任务；新测试仍需手机USB授权、解锁和明确启动。

密码不正确或密文受损时，不写入任何密钥。配置已经修改，或目标目录已有密钥时，导入拒绝覆盖；使用新的解压目录完成迁移。新电脑应使用导入密钥时的同一Windows账户运行系统，换账户时从私人ZIP重新解压导入。

密钥迁移使用scrypt派生密钥与AES-256-GCM认证加密，随机盐和随机IV；恢复后API密钥按目标Windows账户加密存储。原有开发目录的历史明文格式仍兼容读取，本次不改写原电脑数据库。后续在Windows配置页新保存的密钥也采用DPAPI，不在公共配置API中回填。

任务记录保留原输入、原图与原始协议，新的密钥存储不会修改旧测试成绩或最终框架选型。当前迁移验证不包含供应商连通/计费调用，也未在第二台物理电脑运行。

## 维护者

先正常停止原后台并确认没有活动任务；复制本轮干净程序目录到新的私人包目录，然后执行：

```powershell
node scripts/package-phone-history.mjs --target <新私人包目录> --password-directory <ZIP外的新密码查看目录>
```

脚本只复制真机工作台文件，并重建不含明文密钥的模型配置库；密钥仅在内存中读取、加密。快照前后核对配置及记录，历史文本若发现未脱敏密钥则停止。密码查看文件不纳入ZIP，私有数据和输出包继续由`.gitignore`排除。
