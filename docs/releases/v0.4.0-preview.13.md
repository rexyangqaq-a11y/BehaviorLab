## 更新内容

1. 新测试默认不限制请求数、步骤、动作、重复动作及总时长；留空或0表示不限，正整数为自设限额。旧记录冻结限额保持原样。
2. 三框架移除应用与SDK固定30秒模型等待；输出tokens留空使用供应商默认值。服务商、网络、系统资源仍可能中断，仍可手动停止。
3. 截图显示电脑毫秒时间、从正式执行开始的累计耗时；准备阶段单独标记。历史缺失时间不补造，原图字节及SHA不改。
4. 顶部手动HiLog可开始、停止及下载，与输入锁和测试自动日志独立。关闭网页后继续，服务退出时结束。
5. 每个新测试自动从起点准备前开始抓取HiLog，持续至工作进程结束并收尾；组合评估逐项保存，可从详情及证据包下载。32 MiB分卷，磁盘可用空间低于256 MiB时停止，断开或服务退出保留已有片段。

保留36项历史测试（12063事件、331次历史模型请求、1486张原图），可在真机工作台“结果与对比”直接查看。历史没有HiLog的记录明确提示未附带，不补造日志。截图时间使用电脑时钟，HiLog内容中的时间以手机时钟为准。

沿用preview.12已确认的洛书通用机型实测标定（HOP-AL10、指定软件版本与2584×1828屏幕），不绑定原设备编号；不同版本或方向需另行标定。手机桌面起点、模型服务保存提示、自动投屏及v0.4主流程均保留。

## 部署与使用

完整解压Windows包到可写目录，运行03_CHECK.cmd检查，再运行01_START.cmd。历史测试无需连接手机或模型。系统设置中填写模型服务后点击“保存此服务配置”，再回真机工作台选择。新测试须自行连接、授权并解锁手机及配置视觉模型。

更新：运行旧包02_STOP.cmd，备份旧目录，在新目录解压后复制旧包.data；使用原Windows账户，勿将v0.5的schema3库复制给v0.4。回退时停止新包并使用保留的旧目录。详见[部署教程](../DEPLOYMENT.md)、[使用教程](../USER_GUIDE.md)及[本版说明](../V04_PREVIEW13_BACKPORT.md)。
